sequence:

--- APPROACH A: MSAA (try first) ---

Open IMR with an order loaded. Turn the volume down. Ctrl+Windows+Enter to start Narrator, click into the part number table, press the down arrow a few times, Ctrl+Windows+Enter to stop.

Open IMR, load an order.

Paste the handoff prompt into Copilot.

Run 01-probe.ps1 in PowerShell.

Paste its output to Copilot.

Copilot reads the output with you and tells you the three config values, mainly which semicolon field holds the part number.

Open 02-part-search.ps1 in Notepad, put those three values in the CONFIG block, save.

Paste 02-part-search.ps1 into PowerShell. Search box appears. Test it.

--- APPROACH B: OCR (fallback if MSAA shows empty text) ---

If 01-probe.ps1 reports NOT BUILDABLE, or rows show up but the text is blank:

1. Open IMR with an order loaded.
2. Paste 03-ocr-spike.ps1 into PowerShell.
3. During the 4s countdown, click the IMR window.
4. Check the output: are part numbers readable?
   - Clean -> proceed to step 5.
   - Mangled -> raise $Upscale to 3 or $Contrast to 1.4 and re-run.
5. Double-click IMR-Part-Search.bat. One file, nothing else to start.
6. Pick the grid window in the "Page to search" dropdown, or leave it
   on (auto) to match any window titled "Incoming".
7. Type a part number, press Enter. The tool finds the row, moves the
   mouse onto it, and clicks it, so IMR selects that row.

While confirming it aims correctly, set $AutoClick = $false in the
CONFIG block. It then only parks the pointer on the row and clicks
nothing.
